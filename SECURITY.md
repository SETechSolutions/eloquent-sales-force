# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 3.x | Yes |
| 2.x and older | No. These were published as `rob-lester-jr04/eloquent-sales-force` and are no longer maintained. |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the [Security tab](https://github.com/SETechSolutions/eloquent-sales-force/security/advisories/new) of the repository and choose "Report a vulnerability".

Include the affected version, a description of the problem and, if you can, the code or query that demonstrates it. You can expect a first reply within a week. Once a fix is released, the advisory is published and you are credited unless you prefer otherwise.
